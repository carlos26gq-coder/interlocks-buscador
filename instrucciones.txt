SOLVI - comandos rápidos
========================

Instalar dependencias en un entorno nuevo:
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

Ejecutar localmente:
cd scripts
python api.py
Abrir http://127.0.0.1:5000/

Agregar un manual:
python scripts\extract_pages.py --pdf "manuals\nuevo manual.pdf"
python scripts\build_index.py
python -m unittest discover -s tests -v

Despliegue:
- Configurar ADMIN_PASSWORD, R2_PUBLIC_URL, SUPABASE_URL y SUPABASE_KEY en Render.
- Nunca escribir contraseñas o claves reales en este archivo ni en Git.
- Subir los PDF al bucket R2 con el mismo nombre del manual.
- Subir a GitHub data/pages, data/search y data/all_manuals.json.

Si una instalación conserva una versión antigua, abrir /reset una sola vez.

La documentación completa está en README.md.
